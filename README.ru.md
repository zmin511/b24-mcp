# Bitrix24 MCP

Русская документация по проекту MCP для Bitrix24.

## Что это

MCP-сервер для Bitrix24 с упором на практическую автоматизацию задач, комментариев, базы знаний, бизнес-процессов, Bitrix Disk и IM-сообщений.

## Возможности

- подключение к Bitrix24 через webhook
- проверка подключения и scope
- работа с задачами:
  - получение задачи и списка задач
  - создание и обновление задач
  - завершение и отложение задач
  - комментарии и обсуждение задачи
  - чек-листы
  - напоминания
  - участники
  - результат задачи
- работа с Bitrix Disk:
  - список хранилищ
  - работа с папками и файлами
  - перемещение и выдача доступа
- работа с базой знаний:
  - список knowledge sites
  - список и создание страниц
  - обновление страниц и блоков
- работа с бизнес-процессами:
  - список шаблонов
  - запуск процессов
  - просмотр инстансов
- работа с IM:
  - личные сообщения
  - сообщения в чаты
  - персональные уведомления

## Развёртывание

Пример endpoint:
- `https://your-mcp-domain.example.com/b24/mcp`

Пример healthcheck:
- `https://your-mcp-domain.example.com/b24/healthz`

Пример переменных окружения:
- `MCP_AUTH_TOKEN=your_token_here`
- `DATABASE_URL=postgresql://b24_mcp:your_password@db:5432/b24_mcp?sslmode=disable`

## Безопасность

Не публикуйте:
- реальные webhook URL
- реальные токены
- реальные домены прод-среды
- чувствительные внутренние идентификаторы

Используйте в публичной документации только шаблоны:
- `your-mcp-domain.example.com`
- `your-portal.bitrix24.ru`
- `your_token_here`

## Статус

Проект рассчитан на самостоятельное развёртывание: каждый пользователь или команда подставляет свои собственные домены, webhook и токены.
